# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Fixed

- Correct Unicode metadata for `call`, `figma`, `file-download`, `file-upload`, `lightbulb`, `loading`, `lock`, `plane`, `play`, `play-circle`, and `question-mark` to match the established icon font assignments.

### Removed

- Remove the outdated `dist/natura11y-icons-sprite.svg` asset, which is no longer generated by the build. Consumers referencing it must migrate to the individual SVGs in `optimized-svg/` or the icon font before upgrading to a release containing this removal.
- Remove the unused package logo, redundant package ignore file, and contribution pointer file. The README links to the repository contribution guide.
