## Include the millions who read from right to left

Natura11y supports layouts for languages written in right-to-left (RTL) scripts, including:

- Arabic
- Aramaic
- Azeri (Arabic script)
- Divehi
- Fula (Adlam or Arabic script)
- Hebrew
- Kurdish (Arabic script)
- Maninka (N’Ko script)
- Persian
- Rohingya (Hanifi or Arabic script)
- Syriac
- Urdu

Writing direction depends on the script. Some of these languages are also written in left-to-right scripts.

</TextBlock>

</Section>

##  Direction and language HTML attributes

Two key HTML attributes affect the localization of a document: direction (`dir`) and language (`lang`). Both attributes should be present on the `<html>` tag.

The `dir` attribute declares the default text direction. A value of `ltr` sets a *left-to-right* text direction, while a value of `rtl` sets a *right-to-left* text direction.

The `lang` attribute sets the document's default language. A value of `en` sets the language to *English*.

A document written in Arabic, for example, requires both the `dir="rtl"` and `lang="ar"` attributes (Figure 1, line 3).

Translate interface labels and messages alongside page content, and check layouts that combine right-to-left and left-to-right text.

</TextBlock>

## CSS logical properties

Natura11y uses <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Logical_Properties" target="_blank">CSS logical properties</a> for directional text alignment, spacing, positioning, and borders.

With `dir="rtl"` on the `html` tag, styles that use logical start and end values follow the right-to-left direction.
